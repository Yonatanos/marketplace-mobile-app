# Marketplace Mobile App

A React Native application built with Expo, featuring product browsing, search, and cart management with stock validation.

## 🚀 Installation & Setup

### 1. Install Dependencies
```bash
npm install
```

Note: If you encounter dependency issues, use npm install --legacy-peer-deps

### 2. Start the Application

```bash
npx expo start
```

### 📱 How to Run
Once the development server starts, follow the instructions in your terminal:

Physical Device: Scan the QR code displayed with Expo Go (Android) or the Camera app (iOS).

Emulator: Press a for Android or i for iOS to launch the app on your emulator.

### 🧪 Tests
To run the test suite:

```bash
npm test
```

### 🏗 Key Stack
State: Redux Toolkit & Redux-Saga

UI: Styled Components & FlashList

Type Safety: TypeScript
